# AI Usage

FraudNet was developed with OpenAI Codex on September 12, 2026. Codex was used as a coding assistant to scaffold the application, design the component architecture, implement the deterministic data generator and fraud-analysis logic, build the React interface, write automated tests, and help diagnose build and lint issues.

The code, documentation, styling, data model, tests, and application wiring in this repository were AI-assisted during that development session. The developer directed product requirements and reviewed the resulting implementation. Codex access was provided through the development environment; this repository does not know or claim whether the surrounding Codex subscription was free or paid.

No generative-AI service runs inside FraudNet. The risk engine and its explanations are deterministic local code. No external model, API key, or paid service is required to run the application.
